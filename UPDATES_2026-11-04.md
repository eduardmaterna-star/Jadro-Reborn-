# JÁDRO REBORN — novinky z Coding a Code Review, 3.–4. 11. 2026

> Evidence nové práce z obou konverzací. Tento soubor zachycuje doložené výsledky chatů, **nikoli** ověření binárních souborů v GitHub repozitáři.

## Poslední doložená verze: v0.4.0-alpha.6 R1

- **v0.4.0-alpha.5:** Coding uváděl 91 textových zdrojů, sjednocení verzí klient/server/healthz, aktivní místnosti a obnovitelné expedice, validaci save, omezování záloh, frontu 256 událostí, IP rate-limit a řízené ukončení. Lokálně uvedeno Go/race/vet/Node/Python PASS. Distribuční Windows ZIP byl rozdělen na části; samostatný analyzovaný balíček neobsahoval úplné Go/JS zdroje. Windows a reálná 2–4hráčská session NOT RUN.
- **v0.4.0-alpha.6:** Coding uvedl kompletní zdrojové a distribuční archivy, potvrzené ukládání přes `save_request/save_result` včetně `requestId`, opravu obnovy tlačítek po chybné URL, WebSocket reconnect, `world_ready` a CI deklarující Go 1.27.3. Některé lokální Node, Go/race/vet, Chromium a cross-build testy byly hlášeny PASS. Reálné Windows 10/11, WSS a čtyři klienti NOT RUN.
- **v0.4.0-alpha.6 R1:** Coding dodal hratelný Windows ZIP dělený do **šesti částí** pro spojení do `JADRO_REBORN_ALPHA6_R1_WINDOWS.zip`; ve Windows archivu je `JadroReborn-v0.4.0-alpha.6-Windows-x64.exe`. Code Review analyzovalo samostatný **SOURCE ZIP se 169 položkami** a ověřilo 24 médií. Část statických a automatických testů byla PASS, ale skutečný Windows multiplayer a dlouhodobé provozní testy zůstaly NOT RUN. R1 zachovává těžbu, obchod, inventář, grafiku/hudbu a dílčí reconnect/save opravy.
- **v0.4.0-alpha.7:** V chatech jen navrhované zlepšení zvuku a grafiky/výkonu, **nikoli dokončená verze**. Nic nebylo vydáno jako alpha.7.

### Jak aktualizovat tento záznam

Při další verzi z Coding doplnit přesný ZIP/zdrojový strom, hash, seznam změn a skutečně provedené testy. Code Review zapíše konkrétní chyby do existujících Issues nebo nových bez duplicit a označí hotovo až po reprodukované opravě a testu.
